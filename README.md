# Drill Down

A 2D mining game built in MonoGame / C#. Drill deep into the planet, mine and sell ores to fund upgrades, and find the portal hidden at the bottom of the world to teleport to another dimension.

## Goal

Descend through the earth by drilling. Collect ores and sell them to earn money, then upgrade your drill, fuel, cargo, and armor to dig deeper. Somewhere near the bottom lies an unstable portal — reach it to complete the planet and open the way to new worlds.

Watch your fuel and health: run out of either, and it's game over.

## Controls

| Key | Action |
|-----|--------|
| W | Fly up (thruster) |
| A | Move / drill left |
| D | Move / drill right |
| S | Drill down |
| E | Enter shop / portal |
| F | Use Fuel Tank |
| R | Use Repair Kit |
| T | Use Teleport |
| B | Use Bomb |

## Shops

Return to the surface to visit the shops:
- **Gas Station** — refuel
- **Repair Station** — restore health
- **Minerals Shop** — sell your collected ores
- **Upgrades Shop** — improve drill, fuel, cargo, and armor
- **Items Shop** — buy teleports, bombs, fuel tanks, and repair kits

## Items

- **Teleport** — instantly return to the surface
- **Bomb** — destroy a area of blocks around you
- **Fuel Tank** — refill fuel on the spot
- **Repair Kit** — restore health on the spot

## Built With

- C# / MonoGame
- Custom engine components (sprites, animations, audio, UI panels)
